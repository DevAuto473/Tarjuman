# recorded_videos/

فيديوهاتٌ مسجَّلة سلفاً، تتحوّل إلى صفوفٍ في المجموعة بـ:

```
npm run videos
npm run videos -- --dry-run      # يفحص ولا يكتب
npm run videos -- --signer yazid
```

## البنية

مجلّدٌ لكلّ كلمة، واسمه هو التسمية التي تدخل المجموعة:

```
recorded_videos/
    hello/      take1.mp4  take2.mp4  …
    deaf/       take1.mp4  …
    my_name/    …
```

الامتدادات المقبولة: `.mp4` `.mov` `.avi` `.mkv` `.webm`

## ما يُتوقَّع من الفيديو

- **إشارةٌ واحدة**، مقصوصةٌ على الحركة: يبدأ معها وينتهي معها.
- اليدان داخل الإطار، والكتفان مرئيّان (المراسي تُقاس من الجسم لا من اليد).
- إضاءةٌ كافية. ضبابية الحركة هي أوّل ما يُسقط الرصد.

المعدّل والدقّة والمدّة كلّها حرّة: المُعالج يقرأ المعدّل من الملفّ،
ويُعيد التشكيل إلى 30 إطاراً، ويُطبّع المُجمَلات على 20 إطاراً/ث.

## العكس (mirror)

المسار الحيّ يعكس صورة الكاميرا (`MIRROR_FRAME = True`)، والمُعالج يفعل مثله
افتراضاً حتى يتطابق الفضاءان.

لكن تسجيل كاميرا أمامية في الهاتف قد **يُحفَظ معكوساً أصلاً**. وحينها يكون
العكسُ مرّتين، فتنقلب اليمنى واليسرى في المجموعة كلّها بصمت.

الفحص: شغّل `--dry-run` وانظر نسبة اليدين. إن أدّيتَ الإشارة بيمناك وظهرت
«يسرى 90%»، أضف `--no-mirror`.

## ما يُرفض

اللقطة تُرفض ولا تدخل المجموعة إن:

- رُصدت اليد في أقلّ من نصف الإطارات،
- أو بقيت فجوةٌ أطول من ربع ثانية بلا استيفاء،
- أو ردّها `take_quality` لقِصَرٍ أو ضآلة حركة.

التقرير يطبع اسم كلّ فيديو مرفوض وسببه. `--keep-bad` يقبلها مع تحفّظ.
